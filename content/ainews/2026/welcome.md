## 事件概要

博客新增 **AI动态** 专栏（`/ainews/`），用于持续记录 AI 领域的关键事件。与已有的「AI日报」系列不同，这个专栏不追求每日覆盖，而是**只挑值得单独成篇的事件**，允许用图文、视频等更完整的方式讲清楚一件事。

## 为什么重要

日报的形态适合快速扫读，但遇到需要展开的事件——比如一次模型发布背后的技术取舍、一次收购案的前因后果——列表式的结构就不够用了。这个专栏把单条事件当作独立文章来组织：

- **独立入口**：导航栏 `AI动态` 直接进入，不混在文章流里
- **独立标签体系**：使用 `ainewstags` 独立 taxonomy，不与全站 `tags` 混淆
- **多种呈现**：封面图卡片、视频嵌入、纯文本速报三种形态混排
- **事件分类**：`event` 字段区分模型发布 / 产品更新 / 论文研究 / 融资收购 / 政策监管 / 智能体
- **筛选联动**：类型与标签可组合筛选，筛选结果可通过 URL 参数分享

## 如何新增一条动态

```bash
hugo new content ainews/2026/my-event.md
```

然后在 front matter 里填写：

| 字段 | 说明 |
| --- | --- |
| `kind` | 事件类型，决定卡片角标颜色 |
| `cover` | 封面图，外链或走 `imageBase` CDN |
| `video` | 视频 ID：B 站 BV 号，或完整 iframe 地址 |
| `source` / `sourceName` | 原文链接与来源名 |
| `summary` | 一句话摘要，卡片与详情页顶部展示 |
| `featured` | 置顶到专栏顶部焦点区 |
