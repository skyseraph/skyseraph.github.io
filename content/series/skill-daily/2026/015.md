## 🔥 今日趋势

**趋势 1：知识工程全面 skill 化**
观察：graphify（14.8 万星）把代码库连同文档、SQL schema、PDF 转成可查询知识图谱，archify（9.6 万星）把想法与代码变成交互式图表，两者都以单条 skill 接入 Claude Code、Codex、Cursor；同日 Google Chrome 团队的 modern-web-guidance-src 以今日 +1,220 星的速度持续给 coding agent 供给最新 Web 最佳实践。skill 的角色从「教 agent 做事」扩展到「给 agent 供料」。
代表项目：Graphify-Labs/graphify、tt-a1i/archify、GoogleChrome/modern-web-guidance-src

**趋势 2：上下文经济学从「省」走向「审」**
观察：让 coding agent「说原始人语」砍 65% token 的 caveman 总星破 12 万（详见今日 [AI 日报 #015](https://skyseraph.github.io/series/ai-daily/2026/015/)），同一天社区新放出 ctx-receipt 与 skillscope 两个 skill，方向从压缩输出转向先审计：看清 agent 在你打字之前装进了哪些 rules、skills 与 MCP，再谈优化。度量先于优化，token 账单开始有了明细单。
代表项目：Jenoyrex/ctx-receipt、yunloong-Y/skillscope

**趋势 3：Skill 开始拥有自己的 CI 与质检线**
观察：darwin-skill（6,925 星）用「评估→改进→测试→保留或回滚」闭环让 skill 自我进化；新项目 skill-ci 给 SKILL.md 上静态 lint、触发词测试与 PR 门禁；comet（3,299 星）把想法变成带评估的工作流。skill 正在获得与代码同级的工程设施，分发之后的治理问题被摆上台面。
代表项目：alchaincyf/darwin-skill、zhengqiuyang/skill-ci、rpamis/comet
