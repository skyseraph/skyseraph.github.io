## 🔥 今日趋势

**趋势 1：单体 Skill 长成十万星级独立产品**
观察：graphify（14.6 万星）、caveman（11.9 万星）、archify（9.6 万星）过去 24h 内均有推送，三者都以单一场景的 skill 形态存在：代码库图谱化、token 压缩、架构图生成。「一个 skill 做透一个场景」的产品路径从上一期 6 万星量级继续抬升到 10 万星以上。
代表项目：Graphify-Labs/graphify、JuliusBrussee/caveman、tt-a1i/archify

**趋势 2：Skill 安全扫描进入官方工具箱**
观察：NVIDIA SkillSpector（2.6 万星，24h 内多次推送）定位「安装 skill 前的安全扫描」，覆盖提示注入、数据外泄与供应链风险；同窗口内腾讯 AI-Infra-Guard 的 Skills Scan、tech-leads-club/agent-skills 的「验证后 skill registry」保持活跃。skill 供应链安全正从社区工具升级为厂商标配议题。
代表项目：NVIDIA/SkillSpector、Tencent/AI-Infra-Guard、tech-leads-club/agent-skills

**趋势 3：平台方持续供给官方 Skill 与指导内容**
观察：Docker 官方 skills 仓库（容器化应用的构建、测试、调试技能包）、Obsidian 官方 obsidian-skills 与 GitHub awesome-copilot 在 24h 窗口内均有推送；Chrome 团队的 modern-web-guidance-src 当日 +799 星登上 Trending，从命名与形态看走的是与 microsoft/skills 相同的「官方指导内容开源给 agent 用」路线。
代表项目：docker/skills、obsidianmd/obsidian-skills、GoogleChrome/modern-web-guidance-src

## 项目详解（今日榜）

### 1. Graphify-Labs/graphify

| 字段 | 内容 |
|------|------|
| 定位 | 把整个代码库变成可查询知识图谱的 skill |
| Stars | 146458 |
| 语言 | Python |
| 更新 | 2026-11-12 |

**核心功能**
- 以 /graphify skill 形态接入 Claude Code、Cursor、Codex 与 Gemini CLI
- 本地确定性 AST 解析代码库，连同文档、SQL schema、配置与 PDF 一起图谱化
- 每条边附解释，不依赖向量库

**亮点**：以单个 skill 覆盖「理解整个代码库」这一高频刚需，14.6 万星刷新单体 skill 的热度天花板，且 24h 内仍在持续推送。

**局限**：图谱质量依赖解析器对各语言的覆盖，PDF 等非代码资产的抽取深度有限。

**链接**：https://github.com/Graphify-Labs/graphify

| Stars | 119265 |

**局限**：激进压缩可能丢失关键上下文，精度敏感任务需自行权衡。
