## 🔥 今日趋势

**趋势 1：Skill 并入 Agent 记忆与上下文层**
观察：volcengine/OpenViking（4.2 万星）把 Agent Memory、Knowledge RAG 与 Skills 统一为同一套 Context Database；zhayujie/CowAgent（4.8 万星）以 harness 形态把 tools、skills 与记忆装进个人助手并支持自我进化；langfuse 同窗口内持续更新 skill management 模块。skill 正从独立插件变成 agent 记忆体系的一等公民。
代表项目：volcengine/OpenViking、zhayujie/CowAgent、langfuse/langfuse

**趋势 2：Skill 分发层出现标准形态 registry**
观察：openclaw/clawhub（9,555 星）明确以「SKILL.md + 支持文件」为发布单元，提供版本管理、审核钩子、向量搜索与 CLI 友好 API；中文社区 anbeime/skill（9,513 星）自动抓取 GitHub 上万个 skills 项目做分类索引商店。分发基础设施从通用组件目录（上期的 claude-code-templates、skillhub）走向 skill 原生 registry。
代表项目：openclaw/clawhub、anbeime/skill

**趋势 3：单体 skill 的场景从工程扩展到研究与营销**
观察：mvanhorn/last30days-skill（6.7 万星）把「按真实互动与预测市场资金评分」的搜索做成 agent skill，拿过 GitHub Trending 日榜第一；zubair-trabzada/geo-seo-claude（1.2 万星）把面向 AI 搜索引擎的 GEO 优化做成 Claude Code skill。单体 skill 的高星场景不再局限于代码工程。
代表项目：mvanhorn/last30days-skill、zubair-trabzada/geo-seo-claude
