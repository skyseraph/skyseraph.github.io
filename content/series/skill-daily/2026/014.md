## 🔥 今日趋势

**趋势 1：Skill 场景从代码工程走向全面泛化**
观察：逆向与渗透测试技能路由包 reverse-skill（4.4 万星）拿下今日热度第一；ARIS（1.9 万星）把自主 ML 研究封装成纯 Markdown skills；genoffice（1.2 万星）让 agent 本地编辑真实 Office 文件；notebooklm-py（2 万星）把 Gemini Notebook 能力封装为 agentic skill。skill 的主战场不再局限于 coding 工程。
代表项目：zhaoxuya520/reverse-skill、wanshuiyin/Auto-claude-code-research-in-sleep、genspark-ai/genoffice

**趋势 2：Skill 分发与治理走向企业级**
观察：科大讯飞开源 skillhub（5,427 星），提供自托管 skill registry：发布版本化 skill 包、RBAC 权限、审计日志、Docker/K8s 私有部署；Salesforce 官方 sf-skills 当日保持推送；微软 waza 把 skills 评测接入 CI。分发基础设施从上期的社区 registry 延伸到企业私有化场景。
代表项目：iflytek/skillhub、forcedotcom/sf-skills、microsoft/waza

**趋势 3：路由与自进化成为 Skill 编排关键词**
观察：reverse-skill 以「AI 自动路由 + 按需自举工具链 + 自动进化经验库」定义技能路由包形态；新项目 coding-agent-advisor-skill 引入「更强顾问模型」的咨询式编排；meta_skill 用 bandit 算法优化 skill 推荐。skill 之间的组织方式从静态清单转向动态路由。
代表项目：zhaoxuya520/reverse-skill、Dicklesworthstone/meta_skill
