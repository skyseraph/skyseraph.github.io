## 🔥 今日趋势

**趋势 1：「给 AI 产出立审美标准」冲进 10 万星档**
观察：taste-skill（121,808 星，今日有推送）与 archify（100,301 星，今日有推送）同日活跃。两者路线同源：不堆能力，而是给 agent 的产出定验收标准——taste-skill 用 art direction、真实照片与浏览器里的 checker/finish gate 替换 generic AI 落地页；archify 把任何问题、计划或代码库变成结论先行的一页答案。加上上期 cathrynlavery/diagram-design（71,453 星）的「No Mermaid slop」立场，「美学立场 + 可验收交付」已经证明不依赖名人 IP 也能站上 10 万星档。
代表项目：Leonxlnx/taste-skill、tt-a1i/archify

**趋势 2：skill 质量与分发基础设施三线并进**
观察：NVIDIA/SkillEvaluator（4,572 星，今日有推送）、openclaw/clawhub（9,566 星，今日有推送）与 Tencent/AI-Infra-Guard（7,762 星，今日有推送）分别覆盖评测、registry 与安全扫描。昨天微软 waza 入局评测，今天 NVIDIA 的评测框架配齐 CI 门禁、ClawHub 把 skill registry 做到向量搜索与版本治理，腾讯红队平台反过来把扫描能力以 skill 形式上架 ClawHub——分发、质检、安全三端在同一天互相咬合。
代表项目：NVIDIA/SkillEvaluator、openclaw/clawhub、Tencent/AI-Infra-Guard

**趋势 3：新 skill 的交付物从「代码」扩展到「任何产出」**
观察：24h 内新建的 inkworks-skill（345 星）让 agent 用 three.js 画工程图纸风格的交互 3D 说明页；歸藏 MAGI-2 skill 打通视频与代码双向转换；herd-skill（17 星）用 JSONL 消息板跨机器协调多个 coding agent。skill 教 agent 做的事正在越过写代码：产出可视化交付物、驱动视频模型、管理其他 agent。
代表项目：Moh4696/inkworks-skill、op7418/guizang-magi2-skill、ythx-101/herd-skill

## 项目详解（今日榜）

### 1. Leonxlnx/taste-skill

| 字段 | 内容 |
|------|------|
| 定位 | 给 coding agent 装上设计品味的 skill |
| Stars | 121808 |
| 语言 | JavaScript |
| 更新 | 2026-11-26 |

**核心功能**
- 目标一句话讲清：让 coding agent 构建达到 figma.com、x.ai 水准的公司网站，而不是拼装一个 generic landing page
- 规则可执行：plain copy、单一设计系统、one section per screen、左右边缘等宽、真实照片（无素材时用带署名的授权替代图）、真实品牌图标与产品 UI、hero 入场、每页一到两个「dealt moments」、克制微交互；shader 与滚动场景只留给科技/游戏/软件页
- 验收不靠自觉：checker 与 finish gate 在真实浏览器里逐条执行上述规则，不达标不放行
- 全部产出为代码：three.js 级的图来自原语构建，自带 Wikimedia Commons 照片离线可用，无需 API key
- 安装双通道：`npx skills add` 或 Claude Code 插件市场（taste-skill: 命名空间，`/plugin update` 升级）；需 Node 22+ 与本机 Chrome/Edge/Chromium
- 同步发布 TasteCode（tastecode.dev）：taste-skill 的免费开源桌面应用形态，内置设计 agent

**亮点**：12 万星验证「审美立场 + 浏览器验收门」这条路线的上限；与 #020 报道的 diagram-design 同属「给产出定标准」品类，今天该品类首次出现两个 10 万星级成员。

**局限**：聚焦公司网站一类交付物；真实浏览器验收依赖本机 Chrome 环境与 Node 22+；照片替换机制需要网络取图。

**链接**：https://github.com/Leonxlnx/taste-skill

### 2. tt-a1i/archify

| 字段 | 内容 |
|------|------|
| 定位 | 把任何想法/计划/代码库变成交互可视化 |
| Stars | 100301 |
| 语言 | JavaScript |
| 更新 | 2026-11-26 |

**核心功能**
- 一句话起步：向 agent 描述「浏览器调 API、API 查 Redis、未命中查 PostgreSQL 并回填缓存」，得到可探索、可继续修改的交互 HTML 图
- 10 种图型 + Architecture Diagnosis：无需仓库也能画，也可以让 agent 读整个仓库产出带来源的架构图
- 一页答案（explainer）：结论先行、每面板回答一个问题，声明引用编号来源、仓库摘录 pin 到具体 commit；复杂流程/诊断/对比/测试报告会自动生成页面而不是只在聊天里回文字
- Story 与 PR/MR walkthrough 可导出 1080p 视频；单 HTML 文件、四种风格、明暗主题，可导出 PNG/WebP 长图或打印 PDF
- v3.3.2（2026-11-25 发布）为当前稳定版；skills.sh 显示 130K+ 安装；支持 Cursor、Claude Code、Codex CLI、OpenCode、Copilot，安装方式是把仓库 llms.txt 链接直接发给 agent

**亮点**：10 万星 + 13 万安装把「agent 的答案应该长什么样」从聊天流搬到可分享的单文件页面；对复杂回答自动出页、短回答不出页的分寸设计少见。

**局限**：第三方在线服务与付费方案由各自运营方提供，与仓库本身的关系需要用户自行甄别；explainer 的默认自动出页行为需要手动配置开关。

**链接**：https://github.com/tt-a1i/archify

### 3. openclaw/clawhub

| 字段 | 内容 |
|------|------|
| 定位 | OpenClaw 的公共 skill 与插件 registry |
| Stars | 9566 |
| 语言 | TypeScript |
| 更新 | 2026-11-26 |

**核心功能**
- 面向文本型 agent skill（SKILL.md + 配套文件）的公共注册中心：发布、版本化、changelog 与 latest 标签、搜索、star 与评论
- registry 级治理：rename 保留旧 slug 重定向不破坏既有安装；重复 skill 可合并为单一 canonical slug；软删除/恢复区分 owner、moderator、admin 权限，硬删除仅 admin
- 向量搜索替代关键词匹配：OpenAI text-embedding-3-small + Convex vector search
- 本地安装管理：`clawhub install / pin / uninstall / update --all`，pin 冻结的副本不会被更新或强制重装覆盖
- 除 skill 外还提供 OpenClaw 原生包目录：code plugins、bundle plugins 与实验性的 whole-agent Template 包，按 family/trust/capability 元数据浏览
- 技术栈：TanStack Start + Convex（DB、文件存储、HTTP actions）+ GitHub OAuth；安装遥测可用 `CLAWHUB_DISABLE_TELEMETRY=1` 关闭

**亮点**：把 skill 分发从 awesome 合集的「列表陈列」推进到「带版本治理与向量检索的注册中心」；与 #020 报道的 cursor/plugins 官方规格、iflytek/skillhub 企业 registry 一起，分发层三形态（官方/企业/社区公共）已凑齐。

**局限**：深度绑定 OpenClaw 宿主生态；向量搜索依赖 OpenAI embedding 服务；整体仍处快速演进期，schema 与 API 未承诺稳定。

**链接**：https://github.com/openclaw/clawhub

### 5. NVIDIA/SkillEvaluator

| 字段 | 内容 |
|------|------|
| 定位 | NVIDIA 的 skill 评测与质量门禁框架 |
| Stars | 4572 |
| 语言 | Python |
| 更新 | 2026-11-26 |

**核心功能**
- 三层评测：第一层 500+ 静态规则与检测模式，无需 LLM key 即可跑；第二层做 skill 去重与语义重叠检测；第三层 live agent evaluation——带 skill 与不带 skill 对照跑任务，度量 skill lift（skill 对 agent 行为与结果的真实影响）
- 遵循 agentskills.io 的 Agent Skills 规范，是 NVIDIA Verified Skills pipeline 的组成部分
- CI 集成做成了产品：`skillevaluator ci init` 在仓库里开一个 setup PR，接入模板即获得自动质量与安全门禁，无需自建评测代码
- `pip install skillevaluator`，Python 3.12–3.14；配套 arXiv 论文（arXiv:2608.20614）、NVIDIA Developer 博客与 Ask the Experts 直播
- Apache-2.0 协议

**亮点**：昨天微软 waza 入局（#021），今天详解 NVIDIA 这条线——「对照跑分测 skill 的真实增益」与 waza 的「可重复场景 + 评分器」是同一命题的两种解法，评测赛道的两大厂方案现已同台。

**局限**：完整三层评测需要 NVIDIA Build 的免费 key 与 scanner 系统工具；live evaluation 的跑分成本随任务量增长。

**链接**：https://github.com/NVIDIA/SkillEvaluator

### N3. ythx-101/herd-skill

| 字段 | 内容 |
|------|------|
| 定位 | 跨机器协调多个 coding agent 的 skill |
| Stars | 17 |
| 语言 | Shell |
| 创建 | 2026-11-25 |
| 更新 | 2026-11-25 |

**核心功能**
- 基于 herdr 的多 agent 协调：一个协调者 agent 检查各模型配额、写任务 brief、在 herdr 分窗里启动 workers，全部通过一块纯 JSONL 消息板通信
- 后台 watcher 负责 @mention 唤醒，并在超时、看板静默、worker 配额耗尽时向协调者报警；herd-preflight 在派发前逐个 ping 模型返回 ok/quota/no-capacity/timeout
- 完成有硬定义：worker 必须发 [done] 且 brief 里的 check 命令全部通过
- 设计借鉴 Google Antigravity CLI 的 /swarm（消息板、@name 唤醒、[done] 约定），但移出单一 agent 产品：workers 可以是不同 CLI、不同模型、不同机器
- 仓库 52 秒宣传片本身就是 Claude Code 与 Antigravity 两个 agent 用 herd 协调做出来的；自带无需 herdr 与网络的 selftest

**链接**：https://github.com/ythx-101/herd-skill
