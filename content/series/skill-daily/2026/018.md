## 🔥 今日趋势

**趋势 1：省 token 成为 skill 新战场**
观察：caveman（121,428 星，今日有推送）以「why many token when few do trick」的姿态把 token 成本打到台面：自测 Terminal-Bench 4 上同模型每解决任务成本比 Codex 低 21%，整会话输入 token 减少 33.2%；其思路被 Adobe Research 论文引用（八模型 1.4–2.4 倍降本）、JetBrains 官方 A/B 测试、Elasticsearch Labs 复刻。skill 的价值主张从「给 agent 加能力」扩展出一条新赛道：给 agent 的上下文减负。
代表项目：JuliusBrussee/caveman

**趋势 2：skill 分发进入「大超市」时代**
观察：agentic-awesome-skills 把 3,022 个 SKILL.md 打包成可检索、可预览的本地目录（V21.0.0，昨日夜间完成 registry-sync 滚动同步）；同日 claude-code-templates（33,993 星）的组件 registry、OpenClaw 的 clawhub、中文技能商店 anbeime/skill（9,724 星）都在推送。「大库 → 商店 → registry」的三层分发结构成型，skill 的发现、安装与审计正在复制包管理生态的历史路径。
代表项目：sickn33/agentic-awesome-skills、davila7/claude-code-templates、openclaw/clawhub

**趋势 3：Trending 星增前排被 skill 生态包揽**
观察：今日 GitHub Trending 星增前列清一色是 skill 项目：ECC +1,108 星（306,920 星，327 个 skill）、last30days-skill +1,059 星（当选 Trending「Repository of the Day」）、superpowers +822 星（321,658 星）。skill 框架已是 GitHub 全站顶流品类；同时 ECC 在 README 置顶「仅官方渠道安装」警告——第三方镜像可能含恶意软件，30 万星量级项目的供应链风险自查成为标配动作。
代表项目：affaan-m/ECC、mvanhorn/last30days-skill、obra/superpowers

## 项目详解（今日榜）

### 1. JuliusBrussee/caveman

| 字段 | 内容 |
|------|------|
| 定位 | 让 agent 少说少读的省 token skill 与本地代理 |
| Stars | 121428 |
| 语言 | Go |
| 更新 | 2026-11-19 |

**核心功能**
- skill + 本地代理改写 agent 的输入输出：说更少、读更少，代码保持精确
- Terminal-Bench 4 自测：同模型下每解决任务成本比 Codex 低 21%（GPT-6.1 Sol $1.21 vs $1.52），与 Claude Code 打平（Opus 5.5：$5.19 vs $6.04 per solved task）
- 整会话输入 token 减少 33.2%（18 对对照全部答对）；Blocks 代码模式把单次测试运行的输出从 397 token 压到 76
- 兼容 30+ agent，Apache 2.0；同日发布免费 Mac 应用 Caveman Code，用现有订阅与 key 聚合所有 coding agent

**亮点**：Adobe Research 论文引用、JetBrains 官方 A/B 测试、Elasticsearch Labs 按其思路重制——「省 token」第一次拿到产业级背书，而不只是社区玩笑。

**局限**：基准数据为项目方自测（2026 年 11 月、按牌价折算），benchmark 设置与出货形态存在差异；极端压缩对长程推理任务的边界未公开。

**链接**：https://github.com/JuliusBrussee/caveman

### 2. blader/humanizer

| 字段 | 内容 |
|------|------|
| 定位 | 去除 AI 写作痕迹的单功能 skill |
| Stars | 71046 |
| 语言 | Python |
| 更新 | 2026-11-19 |

**核心功能**
- 基于 Wikipedia 编辑指南《Signs of AI writing》归纳 26 个 AI 写作模式，见到即重写
- 主攻五大最强信号：「Not X but Y」句式、一句话金句收尾、伪深刻开场、刻意铺垫、与假想敌争论

**局限**：26 模式以英文写作语料为基础，中文等其他语言的模式覆盖与效果未说明。
