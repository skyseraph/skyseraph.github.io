## 🔥 今日趋势

**趋势 1：工程方法论 skill 的头部竞赛进入 30 万星档**
观察：mattpocock/skills（332,598 星，今日有推送）与 obra/superpowers（326,252 星，今日 +1,003 星居 Trending 前列）同日分别站上 33 万与 32.6 万星。两者路线同源：把资深工程师的完整工作流——拷问需求、建立共享语言、红绿 TDD、子代理并行执行——打包成自动触发的 skill 组合，而非单点技巧。加上上期 Addy Osmani 的 12 万星 agent-skills，「专家方法论整体 skill 化」已确认是当前生态星数规模最大的品类，且头部位置仍在高速换血。
代表项目：mattpocock/skills、obra/superpowers

**趋势 2：token 经济学从经验技巧升级为独立 skill 品类**
观察：caveman（122,747 星，今日有推送）用本地代理 + 行为 skill 让 agent「说得更少、读得更少」，README 给出 33.2% 输入 token 缩减等量化数据，并已获 Adobe Research 论文引用、JetBrains 与 Elasticsearch 的独立复测。同日新建的 omni-token-optimizer 进一步把 Caveman、Punisher Mode、Ponytail 三条优化路线与六篇论文算法统一成 hooks + skills 套件。省 token 正在脱离「提示词小抄」阶段，形成有基准、有复现、有安装管线的一等品类。
代表项目：JuliusBrussee/caveman、Wennington123/omni-token-optimizer

**趋势 3：skill 评测基础设施迎来重量级官方玩家**
观察：microsoft/waza（1,522 星，今日有推送）以 Go CLI 形态提供 agent workflow、skill 与自定义 agent 的评测：可重复场景、评分器、证据链与 CI 回归门，v0.42.0 加入执行溯源与 OpenTelemetry 遥测。同窗口内 rpamis/comet（3,316 星）与当日新建的 vhmns14/skill-eval 亦在推进「skill 效果可测」。继 NVIDIA SkillEvaluator 之后，微软入场意味着评测从社区工具升级为大厂基础设施赛道。
代表项目：microsoft/waza、rpamis/comet

### 3. JuliusBrussee/caveman

| 字段 | 内容 |
|------|------|
| 定位 | skill + 本地代理让 agent 少说少读 |
| Stars | 122747 |
| 语言 | Go |
| 更新 | 2026-11-24 |

**核心功能**
- 口号即方法论：why use many token when few token do trick——让 agent 说得更少、读得更少，代码保持精确
- 量化主张：33.2% 输入 token 缩减（6 个大工具输出任务、18 对测试，18/18 答案正确）；Auto 模式 0.46× Opus xhigh 成本（85 个编码任务，中期数据）；Blocks 把一次测试运行的输出从 397 token 压到 76
- 外部背书：Adobe Research 论文实测八模型 1.4–2.4× 更便宜，JetBrains 做过 A/B 复测，Elasticsearch Labs 为自家场景复刻；曾登 Hacker News 与 GitHub Trending 双第一
- 新发布免费桌面应用 Caveman Code（Mac）：所有 coding agent 收进一个窗口，跑在用户已有订阅与 key 上；Terminal-Bench 4 实测每解决任务比 Codex 便宜 21%（GPT-6.1 Sol：$1.21 vs $1.52），与 Claude Code 在统计噪声内打平（Opus 5.5）
- 支持 30+ agent，Apache-2.0 协议

**亮点**：把「省 token」从提示词技巧做成有第三方引用、有基准页面、能复现的工程命题，并与 #020 的 skill 成本审计方向（infro-skills）形成同一趋势的两端。

**局限**：基准为项目方自测（牌价、自建运行）；省 token 模式对长链推理任务的失败模式披露有限。

**链接**：https://github.com/JuliusBrussee/caveman

### 5. microsoft/waza

| 字段 | 内容 |
|------|------|
| 定位 | 微软的 agent 工作流与 skill 评测 CLI |
| Stars | 1522 |
| 语言 | Go |
| 更新 | 2026-11-25 |

**核心功能**
- Go CLI：为 agent workflow、skill 与自定义 agent 编写 repository、CLI、MCP 三类场景，运行带评分器的可重复试验，并检查过程证据，可接入 CI 做回归门禁
- v0.42.0（2026-11-21 发布）新增：执行溯源、组件清单、运行后遥测、资源预算与隔离契约、可移植外部适配器、运维保障包
- runner submit 与 runner lineage 记录重试、复用等不同执行尝试并输出有序谱系；runner telemetry 从执行文档导出 OpenTelemetry 的 trace、指标与日志（OTLP/JSON 或任意 OTLP/HTTP 收集器）
- 文档站内置 Ask Waza 引用式问答，可粘贴 YAML 与报错排障；文档明确 mock success 只检验 harness 本身，不检验 agent 质量
- 二进制安装即用，`waza update` 自更新，源码构建可选

**亮点**：微软把 skill 评测做成「可重复场景 + 评分器 + 证据链」三件套并直接面向 CI 场景，是继 NVIDIA SkillEvaluator 之后第二个入场的大厂，评测基础设施赛道确认升温。

**局限**：平台与功能矩阵限制多（本地签名、宿主能力显式标记不可用），扩展 registry 尚未随版本落地；v0.42 仍处早期，接口变动风险高。

**链接**：https://github.com/microsoft/waza
