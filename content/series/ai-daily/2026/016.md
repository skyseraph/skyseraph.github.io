**1. GPT-6 Astra 参与破解粒子物理「标准模型」格点定义，50 年悬置问题迎来候选答案**

标准模型成功描述已知基本粒子与三种基本力，却一直缺少一个不依赖微扰展开的严格定义——把它放上时空格点（lattice）的尝试被「手征性」卡了半个多世纪：弱力区别对待左、右手费米子，直接格点化会凭空多出「倍增子」。前人工作（Ginsparg/Wilson、Neuberger 的 overlap 费米子、Lüscher 的相位规则）解决了倍增子难题，但最后一块拼图——完整标准模型的相位设定——悬置超过 25 年。物理学家 Nathaniel Craig 昨日在 OpenAI 博客撰文：他提出「把力场表示到一串逐步加密的格子上、逐级比对允许的费米子态」的细化策略，GPT-6 Astra 把它变成可行构造并主导了详细证明——"GPT‑6 Astra was essential to turning the refinement idea into a working construction. It suggested the right way to carry a given set of force fields onto finer grids, showed that the comparisons on finer grids would converge to a definite answer, and took the lead in developing the detailed proof."。格点场论专家审读质证后，该结果给出了标准模型在有限格距下的候选非微扰定义，"potentially answering a question that had been open for more than fifty years"。Craig 同时强调这是「原则上的答案」而非「实践中的答案」，能否满足反射正性等性质仍待学界检验；文中还指出 OpenAI 此前的 Yang-Mills 存在性证明补上了通向连续统的一块拼图。

**1. Envisioning Agentic Robotics: A New Era of Robotic Systems**

Grid Robotics 团队 12 位作者提出「agentic robotics」的完整议程。文章判断：GPT-6 Astra 的发布标志着机器人新范式——数周之内，前沿模型加 agentic harness 已在多个具身基准上追平或超过任务专用策略，不必再为每族任务训练专门策略。核心概念是 Embodied System 2：基础模型+具身 harness 构成决策中枢，挑战在于把通用推理转化为物理约束（有限反应时间、机械极限、不可逆后果）下可验证的动作。论文据此提出「模型能力+闭环系统性能」双轴评测框架与通往持续自主（sustained autonomy）的研究路线图。

- **影响**：机器人研究的坐标系从「策略训练」切换到「通用推理+具身编排」，评测维度随之重写。

**2. VibePrevisBench: Evaluating Agentic Coding for 4D Scene Generation in Blender**

快手 Kling-Keye 团队 22 位作者推出 agentic coding 的 4D 场景重建基准：coding agent 按剧本在 Blender 里重建可执行 4D 场景并渲染 graybox 代理视频，供可控视频生成模型做前置预览。242 个任务覆盖四类输入（剧本/照片/续写/参考视频），评估走双轨——Rule-based Scene Check 重跑代码、九维比对隐藏真值；VLM-based Screen Check 判断事实能否在代理视频里被认出。评测 11 个前沿 coding agent 得到三个发现：多模态理解（空间与相机运动）拉开模型差距；agent 已掌握基础运镜调度但挑战性请求普遍失败；agent 会自查渲染结果却无法据此纠错。

- **创新点**：把「agentic coding×4D 场景×视频预览」串成一条可自动验证的评测链。
- **影响**：可控视频生成的工程瓶颈被精确定位在「从文本到场景的翻译层」，agent 基建与生成模型的接口有了量化标尺。

> [arXiv:2611.15789](https://arxiv.org/abs/2611.15789) · 提交时间：2026-11-11 · ⬆️ 74 upvotes (HuggingFace Daily Papers)

**3. Rethinking in Spikes: Mitigating Hallucinations in MDLMs with Step-Aware Decoding**

多模态扩散语言模型（MDLM）的迭代去噪总体不确定性下降，但少数步骤会出现与幻觉强相关的「熵尖峰」。StepRefine 是即插即用的解码策略：熵尖峰步骤切换到概率加权嵌入以保留多个推理假设，做多轮连续精修；精修控制器监控分布稳定性，稳定后即切回标准离散去噪。跨多个 MDLM 的实验显示幻觉显著缓解。

- **创新点**：用相邻时间窗的熵偏差在线识别异常去噪步骤，把「哪一步出问题」变成可测信号。
- **影响**：给扩散式语言模型的可靠性提供廉价的推理时补丁，不改训练即可生效。

> [arXiv:2611.12901](https://arxiv.org/abs/2611.12901) · 提交时间：2026-10-14（今日登榜）· ⬆️ 18 upvotes (HuggingFace Daily Papers)

**4. MEM-SQL: Memory-Empowered Text-to-SQL**

八位作者提出记忆增强的 Text-to-SQL：先发 HARE 基准——1,600 个请求源自 823 条已验证查询，专门考察「复用历史 SQL」的能力，标注每条请求保留哪些组件、需要哪些编辑。MEM-SQL 分层存储整查询模板、可复用 SQL 块与概念-schema 映射，配合按需 schema linking。六个语言模型上，执行准确率均值从直接生成的 37.1% 提到 50.0%，输入 token 平均少 76.6%、延迟降 68.8%——已验证的历史能让生成又准又便宜。

- **创新点**：把「查询历史」当作一等资产建分层记忆，而不是每次从零推理。
- **影响**：agent 长期使用同一数据库时，记忆层成为成本与准确率的双重杠杆。

> [arXiv:2611.18338](https://arxiv.org/abs/2611.18338) · 提交时间：2026-11-13 · ⬆️ 13 upvotes (HuggingFace Daily Papers)
