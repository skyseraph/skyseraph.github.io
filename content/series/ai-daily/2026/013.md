## 🔥 焦点事件

**1. Google 发布 Gemini 4 Hydrogen：给所有人的「日常执行」模型**

Google 官方博客上线 Gemini 4 Hydrogen，Gemini 4 系列至此有了三层分工。原文一句话说清定位："While our frontier models, Gemini 4 Carbon and Gemini 4 Argon, excel at deep, long-horizon reasoning on your hardest problems, Hydrogen is built for rapid execution across diverse agentic workflows."——Carbon/Argon 管深推理，Hydrogen 管快执行，并首次把 Gemini 4 铺到全部受众：AI Studio 各层级、Gemini API、企业版、Gemini App、Google Search 与 Antigravity 订阅用户。数字：Artificial Analysis 智能指数高档位 51 分超过 Argon 的 50，xhigh 新档冲到 54；定价 1M token 窗口一口价 $1.50 输入 / $7.50 输出；较 Gemini 3.8 Flash 任务快 2.5 倍、Terminal-Bench 4.1 分数翻三倍多（57% vs 18.2%）、虚构陈述少 5 倍以上。安全面，agent 任务越界行为减少最高 81%，对间接提示注入的韧性提升 2.3 倍（Gray Swan IPI），20 万条审计对话中思维链可读性保持 99.9%。同日 Antigravity 发布 Orchestrator：同一会话内动态切换 Carbon 与 Hydrogen，Terminal-Bench 4.0 上以少 24% 配额、快 19% 的代价逼近 Carbon 成功率——Carbon 做协调者、Hydrogen 做 worker/verifier 的并行 agent 编排成为默认形态。加上本周的 Decisions API（见 [#012](https://skyseraph.github.io/series/ai-daily/2026/012/)），Google 一周内补齐了「生成—决策—编排」三层。

**2. Edge0-145B 开源：145B 参数装进笔记本，29GB 内存、80+ tokens/s**

Edge0 开源 Edge0-145B 与 Edge0-120B，官方称 "the world's first open-source on-device AI model with 145 billion parameters"。实测口径：兼容笔记本上峰值内存 29GB、解码 80+ tokens/s、预填充 1,100+ tokens/s、典型功耗约 120W、128K–256K 上下文速度基本不衰减。跑得动的关键是模型与推理引擎协同设计：每 64 个专家共享两块大矩阵，145B 参数中每个推理步只激活约 10B；GPU 内存、系统内存（约 40GB 专家库）、SSD（约 48GB 词表）三级流水加载，CPU 与 GPU 并行计算加投机解码。成绩单（注意：全部来自 Edge0 内部评测，无第三方复核）：DeepSWE 1.1 得 64.6 超过 Qwen3.8-Flash-Next 的 58.7；GPQA-Diamond 90.4 逼近 Claude-Opus-4.6 (Max) 的 91.3；IFBench 80.6 对 Claude 的 62.5；六基准均值 72.8 对 Qwen3.8-Flash-Next 的 71.7，内存只占其估算值的四成。官方演示包括 Blender 里从零建曼哈顿城市场景、给奇幻 RPG 生成中世纪都城并渲染 20 秒飞越镜头、给真实无人机写避障找物程序、KiCad 上完成 PCB 设计。端侧叙事今日有第二只脚：Show HN 项目 smolmaxxing（「让 LLM 跑在又小又旧的设备上」）拿下 390 分，与昨日 Apple 本地模型 Mac 应用传闻（见 [#011](https://skyseraph.github.io/series/ai-daily/2026/011/)）连成同一条线——本地推理的能力上限一周内被反复抬高。

> 来源：[Edge0 Blog](https://edge0.ai/blog/introducing-edge0-145b-frontier-ai-capabilities-on-your-own-computer) · 发布时间：2026-11-12 18:00 UTC · ⬆️ 273 points (Hacker News)；smolmaxxing：[GitHub](https://github.com/hyperionaidev/smolmaxxing/)（15:23 UTC · ⬆️ 390 points）

**5. Brave Search API 接受 x402 agentic payments**

Brave 官方博客宣布 "Brave Search API now accepts agentic payments via the x402 protocol"。AI agent 调用搜索 API 时可以用 x402 协议按次即时付费，不需要账号、合同或预充值。与昨日美联航禁止 AI agent 代客订票（见 [#012](https://skyseraph.github.io/series/ai-daily/2026/012/)）对照着读：一边是航司把机器流量挡在门外，一边是搜索 API 率先给 agent 开出原生支付通道。agentic commerce 的分歧不在「要不要」，而在「谁先收费、按什么原语收费」。

## 📄 论文速递

**1. Scaling Mathematical Proof Supervision from Structured Textbooks**

今日 HuggingFace 每日论文榜第一（30 upvotes）。把 2,118 本大学数学教材转成约 38 万条结构化证明监督记录（TOME-Math 语料），保留章节顺序、命题-证明链接、依赖引用与出处——而常规做法把数学监督压平成孤立题解对，丢掉了课程结构与证据结构。团队用这些结构信号探索课程学习式训练。

- **创新点**：证明数据从「题解对」回到「教材组织」，课程结构成为可训练信号
- **影响**：给数学推理与证明类模型提供了带教学法的监督数据供给

> [arXiv:2610.40394](https://arxiv.org/abs/2610.40394) · 发布时间：2026-10-29（今日登榜）· ⬆️ 30 upvotes (HuggingFace Daily Papers)

**2. Incentivizing Self-Learning in Large Language Models via Reinforcement Learning**

InternLM 团队研究「自我学习」：模型自主检索长篇参考材料、边读边学、随即应用到解题，而不是依赖预装配好的上下文。任务设定在教科书数学题上，用强化学习激励「检索—研读—应用」的闭环。

- **创新点**：把「学习行为本身」作为 RL 奖励对象，而非只奖励答案正确
- **影响**：陌生领域的 knowledge acquisition 与 reasoning 耦合，是 agent 长期自主性的基础能力

> [arXiv:2610.39671](https://arxiv.org/abs/2610.39671) · 发布时间：2026-10-29（今日登榜）· ⬆️ 21 upvotes (HuggingFace Daily Papers)

**3. Termination Lag: Coding Agents Solve Early but Stop Late**

给 coding agent 的浪费起了个名字：termination lag，从首个正确补丁到运行结束之间的步数。跨 5 个模型、2 个 agent 框架、3 个 SWE-bench 数据集记录并测试执行中的每个补丁，发现 38–82% 的成功运行在第一次源码编辑时就已经正确，而解题后的步骤仍占中位数 35–37% 的开销。

- **创新点**：把「何时停」从工程细节变成可测量的研究对象
- **影响**：停止准则是 agent 成本里被忽视的大头——模型已经对了，token 还在烧

> [arXiv:2611.14960](https://arxiv.org/abs/2611.14960) · 发布时间：2026-11-11

**4. GTAGym: Real AAA Game Tasks Environment for Evaluation and Reinforcement Learning**

OpenMOSS 用 GTA V 主线任务构建 agent 评测与 RL 环境：GTAVBench 含 9 个任务族 103 个在线任务，另有 47 个基于图像的射击任务，任务结果可自动验证。AAA 游戏的感知-推理-控制链条比合成环境稠密得多，自动验证则解决了此前只能人工标注的瓶颈。

- **创新点**：第一个任务结果可自动验证的 AAA 游戏环境
- **影响**：具身与游戏 agent 的评测从「人看录像」走向「机器打分」

> [arXiv:2611.13028](https://arxiv.org/abs/2611.13028) · 发布时间：2026-11-09（今日登榜）· ⬆️ 11 upvotes (HuggingFace Daily Papers)
