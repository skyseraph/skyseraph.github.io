## 需求雷达

### 需求 1：agent 的时效知识供给

**痛点**：Chrome 团队亲自维护 agent 版 web 规范库并单日收获 1200+ 星（[GitHub](https://github.com/GoogleChrome/modern-web-guidance-src)），反证在此之前的普遍状态——agent 用的平台知识冻结在训练截止，前端平台每月都在废弃 API、改默认行为。
**场景**：20 人前端团队，coding agent 生成的代码用了三个月前废弃的 API，CI 才发现，返工半天；平台团队想给全公司的 agent 统一喂「本月 web 平台变更」包，没有现成格式。
**机会**：目标客户是平台团队/工程效率团队；切入方式是按月打包平台变更的 diff 包（可从官方 guidance 库起步），以 CLI 或 MCP 形式注入 agent 上下文；与通用文档工具的差异是「变更集」而非「知识库」——只喂 delta，不重复静态知识。
